# REQ-012 배치 측정 리포트 — 설계 문서 (정답 예시)

## 1. 문제
배치(로트) 측정 결과가 회차별 CSV로 흩어져 있어 배치 전체 상태를 한눈에 보기 어렵다.

## 2. 원하는 결과
- 배치 1개 → HTML 리포트 1장 + 요약 CSV 1개 (메일 첨부로 공유, 서버 업로드 없음)

## 3. 요구사항
| R | 내용 | 확인 방법 |
|---|---|---|
| R1 | 배치별 성공률 · 무응답(타임아웃) 비율 | 원본 CSV를 직접 센 값과 일치 (테스트) |
| R2 | 온도 조건별 결과 | 온도 4종 행이 모두 나옴 (테스트) |
| R3 | 리비전 비교 (선택) | 리비전 A/B가 둘 다 있으면 비교 표 출력 |
| R4 | HTML 1장, 외부 라이브러리 · 인터넷 없이 | 표준 라이브러리만 import (테스트) |
| R5 | 요약 CSV 1개 | 열 이름 고정 (테스트) |
| R6 | 기존 측정 · 리포트 기능 동작 불변 | 기존 테스트 전부 통과 |
| R7 | 5,000행 배치를 10초 안에 | 생성 데이터로 시간 측정 |

## 4. 바뀌는 파일 / 새 파일
- 새 파일 : `mx_host/batch_report.py`, `tests/test_batch_report.py`
- 바뀌는 파일 : 없음 (cli 연결은 T4에서)

## 5. 작업 순서
T1 집계(R1 · R2 · R3) → T2 HTML(R4) → T3 요약 CSV(R5) → T4 CLI 연결 · 성능(R6 · R7)

## 6. 증명할 테스트
- T1 : 손으로 센 작은 표와 집계 결과 일치
- T2 : HTML에 표 2개 · 외부 링크 없음
- T3 : 열 이름 · 행 수
- T4 : 기존 테스트 전부 + 5,000행 10초

## 7. 위험 — 기존 측정 기능이 바뀌면 안 되는 곳
- `report.py`의 텍스트 리포트 형식 (다른 팀 스크립트가 읽음)
- 결과 상태 값 'OK' / 'NO_RESPONSE'

## 8. 열린 질문
- 리비전 비교에서 표본이 적은 조건 표시 방법 (미정)
