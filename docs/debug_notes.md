# 디버깅 기록 — 고온 무응답 (정답 예시)

- 현상 : 리비전 B, 125°C에서 명령 무응답 약 3% (고객 메일) · 측정 CSV에서 B@125 무응답 2.56%, 재시도 31%
- 재현 : tests/test_hightemp_timeout.py — 응답 4.4 ms인 가짜 장치에서 3회 모두 타임아웃
- 원인 : `session.fwt_ms`가 FWT를 정수 ms로 내림(4.833 → 4) + 여유 시간 없음. 리비전 B는 고온에서 응답이 최대 +0.9 ms 늦어짐(데이터시트 v1.3 ERR-03) → 4 ms를 넘는 응답을 놓침
- 수정 : 내림 없이 계산 + t_GUARD 0.5 ms (wait_ms)
- 증거 : 수정 전 실패하던 재현 테스트가 테스트 수정 없이 통과
- 남은 의문 : 고객 시험 툴 1.4.2 사용처 업데이트 범위
