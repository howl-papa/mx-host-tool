# 테스트 전략 (정답 예시)

| 모듈 | 자주 바뀜 | 실패 시 피해 | 지금 테스트 | 우선순위 |
|---|---|---|---|---|
| session (FWT · 재시도) | 중 | 상 (고객 이슈) | 재현 테스트 | 1 |
| anticoll | 하 | 상 (태그 누락) | 있음 | 2 |
| batch_export | 상 | 중 (다른 팀 데이터) | 없음 | 3 |
| store | 중 | 중 | 기본 1개 | 4 |
| report | 상 | 하 | 있음 | 5 |

## 코드가 장비에 대해 가정하는 것
응답 시간 범위 · 태그 수 · FIFO 크기 · 온도별 지연 · 장비 연결 여부

## 장비 없이 테스트하려면
`hal.Transport` 인터페이스를 지키는 모의 칩(tests/sim_chip.py)으로 바꿔 끼운다.

## 이번에 만들 테스트
1. 고온 지연 응답 회귀 2. 무응답 시 재시도 횟수 3. 태그 여러 장 (5 · 9장)

## 이번에 하지 않을 것
실제 장비 시험(교육 환경에 없음) · 속성 기반 테스트(범위 밖)
